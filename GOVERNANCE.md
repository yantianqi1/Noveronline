# Governance

MiroFish-Novel is currently maintained by the repository owners.

## Maintainer Responsibilities

- Review issues and pull requests.
- Keep security-sensitive reports private until fixed or reasonably mitigated.
- Protect user manuscript data, local databases, prompt traces, and API credentials.
- Keep public documentation aligned with the current architecture.

## Decision Making

Project direction is maintainer-led. Significant changes should be discussed in an issue or design document before implementation, especially when they affect:

- Database schema or migration strategy
- LLM module contracts and prompts
- Public API contracts
- Worldline semantics
- Writer Agent workflows
- Security and data-retention behavior

## Contributor Path

Regular contributors may be invited to help triage issues, review PRs, or maintain specific areas after demonstrating consistent, high-quality contributions.
