# 08-旧数据逐字段映射与迁移脚本规范

## 1. 目标

本文件把旧系统中的所有主要数据源映射到新系统目标模型，给出逐字段去向、迁移方式和脚本约束。

迁移原则固定如下：

1. 旧事实先导入，不先改写。
2. 长文本与大 JSON 只入对象存储，数据库保存元数据与索引。
3. 凡是当前已经明显属于派生索引的数据，在新系统中只能做 projection，不能继续冒充主事实源。
4. 所有迁移脚本必须幂等。

## 13. 迁移脚本规范

所有迁移脚本统一要求：

1. 路径：`migration/scripts/*.py`
2. 输入：
   - 旧项目根目录
   - 目标 PostgreSQL DSN
   - 对象存储 bucket
3. 输出：
   - 结构化迁移报告
   - checksum 对账结果
   - anomaly 报告
4. 幂等：
   - 基于 `project_id / artifact_sha256 / legacy_primary_key`
5. 模式：
   - `dry-run`
   - `import-only`
   - `verify-only`
   - `activate`

### 推荐脚本拆分

- `migrate_projects.py`
- `migrate_seed_artifacts.py`
- `migrate_archives_and_memories.py`
- `migrate_chapter_meta.py`
- `migrate_worldline_sessions.py`
- `migrate_worldline_runtime.py`
- `migrate_llm_facility.py`
- `verify_project_checksum.py`
