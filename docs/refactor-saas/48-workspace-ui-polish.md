# 48. 作品书架与入口交互精修

日期：`2026-09-07`

## 目标与边界

面向长期写作的小说作者，优化「登录 → 找到作品 → 创建或进入作品 → 打开写作台」路径。实现仅使用 `apps/web` 的 Next.js 15、React 19、Tailwind 4、Lucide 和既有纸墨 token，数据继续来自真实 Go API 和同源 Next BFF。

不改变 Writer 的 manuscript-primary + conversation-first 结构，不扩展领域 API，不执行 Legacy cutover。实施与验收状态只记录于 `24-current-development-progress.md` 和活动任务板。

## 已核实的问题

- 原书架书名仅有竖排题签，七字后的渐隐使作品难以区分；8.5px 权限印章不满足现有 12px 阅读下限。
- 项目计数重复出现，新建占位书会独占下一层书架；大幅悬停旋转、逐本延迟与日常选择任务不匹配。
- 页头在长账户名和窄屏下争抢宽度；书架缺少作品名称搜索。
- 创建表单缺少明确的关闭后焦点恢复；账户菜单缺少完整键盘焦点管理；移动导航虽然声明 modal，但背景仍可被 Tab 到达。
- `GET /v1/me` 作品字段为 `name`；创建端点的请求与响应为 `title`，已以 `projectadmin/handler.go` 与 `service.go` 核实。

## 设计决策

采用「保留线装书识别、提高可扫描性」方案。仅修补字号仍不能解决长书名和空占位层；完全换成管理表格会丢失既有文学风格。封面保留六种稳定配色，完整书名与权限移到封面下横排呈现。

- 基础色沿用纸 `#f7f2e9`、墨 `#171a1b`、朱砂 `#8f211b`；朱砂仅用于品牌、主要动作、选中与焦点。
- 字阶沿用标题 22/30px、作品名 18px、UI 14/16px、辅助信息 12px；使用已加载的 Noto Sans SC / Noto Serif SC。
- 间距按 8px 递进；主区最大 1152px；小屏页边距 16px。作品使用自适应网格，长标题自然换行，页面不横向溢出。
- 新建集中在页头；空书架时主操作随空态呈现。移除占位书和重复计数卡。
- 搜索仅过滤真实返回的作品名称；查询同步 `q` URL 参数，刷新、打开作品后返回仍保留。
- 创建使用原生 dialog 保护输入焦点，显式标签、就地错误、提交中状态、Escape/关闭按钮和焦点恢复齐全。
- 作品使用真实链接；账户菜单支持键盘，移动导航复用原生 dialog 隔离背景焦点。
- 动效沿用 160/220/280ms，取消逐本延迟与大幅旋转，尊重 reduced-motion。

## 实施计划

1. 将书架数据加载、内容与空/错/加载状态分为独立文件；在 `project-card.tsx` 与三份 shelf CSS 中实现封面、横排书名、网格与页头。
2. 在 `shelf-content.tsx` 中接入名称搜索、URL 恢复和唯一新建入口。保持 `fetchCurrentUser()` 和 `createProject()` 数据契约。
3. 新增小型共享 `components/ui/modal.tsx`，用浏览器原生 `showModal()` 实现焦点隔离与恢复；接入创建表单及 `workbench-nav-drawer.tsx`，补全 `user-menu.tsx` 键盘与小屏行为。
4. 执行 Web 现有 `npm test`、`npm run typecheck`、`npm run build`。若真实栈启动暴露既有阻断，仅修复阻断且记录证据。
5. 所有会写数据的验收通过 `infra/scripts/run-live-test-stack.sh --app -- <command>`，在独立 `mirofish_test_*` 库和 volumes 上运行。使用真实认证/BFF/Go API；375、768、1024、1440px 检查搜索、创建、进入 Writer、键盘、长标题、无横向溢出及 reduced-motion。退出清理独立栈。

### 真实浏览器发现的入口边界

- 作品入口由 `project-session-gate.tsx` 先读取真实 `/api/me`，匹配路由项目及活动租户，再挂载工作台，覆盖中键新标签和直接 Writer 链接。取消旧请求后不得写入浏览器选择；存储不可用时显式提示重试，401 保留原路径返回登录。
- 创建表单保留真实会话/CSRF 错误，登录过期时提供重新登录入口；封面装饰题签保持单列并显示省略标记，200 字完整标题仍在封面下自然换行。
- 写作台原顶栏在手机上发生控件重叠。修复仅调整顶栏：沿用 `wide = 1200px` 与 `stack = 861px` 断点；窄屏首行放章节切换和 44px 新章节按钮，四个视图在同一顶栏第二行等宽展开，保存状态独立可见。项目主区用剩余高度伸展，避免增高后的顶栏挤掉画布底部。
- 顶栏实现落在 `project-header.css` 与 `writer-canvas-top.tsx`；真实浏览器以每个可见按钮中心的命中元素和边界检查遮挡，并验收新章节和视图切换。无需新增 UI 库，也不改变稿件与 Agent 的主次关系。
- 新章节首段没有 Markdown 标题时，正文编辑曾误走标题拼接分支，每次输入在正文前插入两个换行；拼接器现在仅为真实标题补分隔行，浏览器校验输入、保存、视图切换与刷新后的正文完全一致。
- Agent 输入框在手机布局隐藏时曾测得零高度，切回桌面后只剩 12px。输入框现在观察自身宽度变化，在重新显示时重算高度；浏览器同时检查完整可见与 Shift+Enter 换行，验收不发送模型请求。
- 键盘退出登录时，先把焦点移回账户触发器，再禁用提交项，避免失焦关闭菜单并隐藏真实服务错误。验收等待退出请求的真实响应，只检查账户区域内的错误提示；页面切换等待内容就绪。`MIROFISH_UI_TIMEOUT_MS` 可覆盖浏览器默认 30 秒等待，适应本机多栈重启时已观测到的 18 秒登录请求。
