# Mobile Visual QA Checklist

对照设计稿下限；交付必须 **≥ 设计稿**（更干净、更丝滑、更可用）。

## Viewports

- 375×812
- 390×844
- 430×932
- 768×1024（平板过渡）
- 1024×768（窄桌面：桌面壳 + 内容双列）
- 1280×800（宽桌面：主栏 + 上传轨）

## Layout bands

| 档位 | 视口 | Chrome | 内容 |
|------|------|--------|------|
| Desktop | ≥1200 | 侧栏 + 命令栏 | 主栏 + 右侧轨 |
| Narrow desktop / tablet | 861–1199 | 侧栏 + 命令栏（可略收窄） | **双列或主+轨**，禁止全宽瀑布 |
| Phone | ≤860 | 顶栏 + 底栏 | paper stack / 单列 |

## Shell

- [ ] 底栏四 Tab：总览 / 资料 / 创作 / 我的（仅 ≤860）
- [ ] 激活态印章红细线 + 图标着色
- [ ] 顶栏小说切换可达；⋯ 打开更多 sheet
- [ ] safe-area 底栏/顶栏不贴刘海与 Home 指示条
- [ ] 无横向溢出（`documentElement.scrollWidth <= clientWidth`）
- [ ] Writer 路由隐藏全局底栏（沉浸），composer 可达
- [ ] **1024 / 1280：桌面侧栏仍在，总览主区与上传轨并排，非全宽卡片纵向码放**
- [ ] **861–1199：资料 / 我的入口为 2×2 卡片，非手机单列列表**

## Screens vs design

| Screen | Must match or beat design |
|--------|---------------------------|
| 登录 | 书卷气质、主 CTA、密码显隐、loading |
| 总览 | 下一步优先、失败人话、重试/取消；中间带双列结构 |
| 资产空态 | 中心空态 + 创建 CTA |
| 资料 hub | 四入口卡清晰；≥861 为 2×2 |
| 图谱 | 空态人话，非裸 NOT_FOUND |
| 世界线 | 主 CTA 清晰，更多操作可折叠；中间带保留轨 |
| 角色 | 空态说明 + 主表单 |
| 写作 | 默认 Agent；采用正文真实落稿 |
| 我的 | 账户 + 模型 + 安全 + 退出；≥861 入口网格 |

## Motion / a11y

- [ ] 过渡 120–220ms，`prefers-reduced-motion` 关闭动效
- [ ] 触控目标 ≥ 44px
- [ ] Sheet/抽屉 Esc 关闭，焦点可回
- [ ] 错误码不作为作者主文案
