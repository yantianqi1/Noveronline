许七安觉得自己的运气实在不好。

明明是个穿越者，明明脑子里装着几千年的诗词歌赋，偏偏投生到了这个鬼地方——一个连科举都没资格参加的武夫家庭。更要命的是，他现在的身份是大奉王朝京兆府辖下的一名典史，说白了就是个底层公务员，整天跟鸡毛蒜皮的案子打交道。

今天又是无聊的一天。

许七安从县衙出来，伸了个懒腰，骨节咔咔作响。炼精境的修为让他的身体素质远超常人，但这点实力在真正的强者面前根本不够看——他那个当捕头的二叔许平志就是练气境，比他高出一个大境界，一巴掌就能把他拍趴下。 改写选区 ⌘I 续写此段 引用到对话

“七安，走，喝酒去。”

同僚李典史从后面追上来，拍了拍他的肩膀。这人三十出头，圆脸微胖，一副市井油滑的模样。

许七安摆摆手：“今天不行，家里有事。”

“得了吧你，谁不知道你们家那点破事。”李典史嘿嘿一笑，“你那婶婶又给你脸色看了？”

许七安没说话，算是默认。

说起来也怪他自己。穿越过来三年了，除了练出一身蛮力，什么正经事都没干成。许家在京城算是底层官吏家庭，二叔许平志在衙门当捕头，勉强维持一家生计。婶婶李茹是个精明势利的女人，早就看这个吃白饭的侄子不顺眼，明里暗里没少给脸色。
