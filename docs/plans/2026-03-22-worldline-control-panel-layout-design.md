# 世界线控制台布局优化设计

**Goal:** 让世界线控制台从“控件堆叠”调整为清晰的三段式操作面板，使用户能按“选档案 -> 设变量 -> 执行动作”顺序完成操作。

**现状问题**

- 档案选择区体量过大，压缩了创建会话和后续操作区的识别度。
- “初始变量 / 创建会话 / 推进一步 / 注入变量 / 反馈”混在同一视觉层级，主次不清。
- 会话状态只以内联 chip 形式出现，缺少明确的当前阶段提示。
- 在较窄布局下，按钮和表单上下堆叠方式缺少分组，容易形成“散落感”。

**设计方向**

- 采用三段式结构：
  1. 选择源档案
  2. 配置初始变量并创建会话
  3. 在已创建会话上执行推进和变量注入
- 为第二、三段增加独立分区标题与说明，降低用户在单个大卡片中寻找操作入口的成本。
- 将会话 ID、会话范围、当前状态整合为摘要区，强化“当前处于哪个阶段”的认知。
- 将主按钮与次按钮做层级区分：创建会话是唯一主操作，推进和注入属于会话内操作。

**实现边界**

- 不增加新业务能力，不改变 API 调用与状态管理。
- 优先改模板结构与局部样式，尽量不触碰外层数据流。
- 保持现有暖色纸面视觉体系，只优化空间组织、对齐与层级。

**预期结果**

- 用户进入面板后能先看见操作路径，而不是先面对一大片档案卡片和零散按钮。
- 会话创建前后，界面能自然切换为“配置态”和“控制态”。
- 在桌面和较窄宽度下都能保持按钮区、输入区、反馈区分明。
