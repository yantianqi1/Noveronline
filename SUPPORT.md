# Support

MiroFish-Novel is an open-source project in active development.

## Questions

Use GitHub Discussions if enabled, or open a GitHub issue with the `question` label.

## Bugs

Open a bug report using the issue template. Include:

- Operating system
- Python and Node.js versions
- Backend and frontend commands used
- Expected behavior
- Actual behavior
- Relevant logs with secrets and manuscript content removed

## Security

Do not report security vulnerabilities in public issues. Follow `SECURITY.md`.
